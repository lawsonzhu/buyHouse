左邻右里：一个小区六种房价，先认组团再谈价

南京 · 江宁区岔路口 / 南京南站板块 · 宏运大道 1188 号 · 50 栋约 2,100 户 · 2005–2014 分期 · 成交参考锚 约 18,000 元/㎡（推断） · 取数 2026-11-04

结论一：160 万在左邻右里只够买 73–88㎡ 两房，落地基本花完；同样的钱在明月港湾能买 100–110㎡ 三房、金王府能买 93–97㎡ 三房。它比明月港湾贵约 50%，买的不是面积，是已通车的双地铁 + 南站。

结论二：这不是一个小区，是六个价格。丹桂苑/银桂苑/金桂苑 20,000 上下、香桂苑 17,551、泊客公寓 15,878、枫叶苑 13,563 且整组团是拆迁安置房。不认组团谈价，谈的就不是同一套房子。

结论三（最重要）：链家把本小区权属列为「商品房 / 房改房 / 动迁安置房 / 使用权 / 乡产 / 私产」六种并存。使用权房、乡产房不能按揭、不能正常过户。看房第一件事不是谈价，是翻房本的"权利性质"。

数据边界：近 3 个月链家可查 5 条签约记录，价格全部隐藏（"暂无信息"）。本页成交单价是按挂牌价与本板块议价规律推断，不是实价。要实价只能靠经纪端内网或你发截图。

八、买之前必须核实的四件事 按优先级

  1. 房本"权利性质"，不是只看"商品房"三个字。链家把本小区权属列为商品房/房改房/动迁安置房/使用权/乡产/私产六种并存。使用权房、乡产房无法按揭、无法正常过户，价格再低也不能碰。要求业主提供房本首页照片 + 不动产登记查询，别听口头。
  2. 学区平台标错，别信页面。链家/贝壳当前挂的"雨花外国语小学（南站校区）"属于雨花台区，而左邻右里是江宁区，跨区不可能对口。真实对口是宏运学校（东外分校，九年一贯制）。签约前拿房本到江宁区教育局查当年划片，学区政策每年都可能调整。
  3. 物业现状要亲眼验。十年投诉的核心是门禁瘫痪、监控失效、绿化死亡。白天去一次看楼道和绿化，晚上 8 点再去一次看门禁是否真的启用、车停在哪。别在样板照片里判断。
  4. 组团要写进合同标的。同一小区，枫叶苑（安置房）13,563 与金桂苑 20,467 差 51%。合同、房源编号、门牌必须明确到"XX 苑 X 幢"，避免用"左邻右里"这个大盘名做模糊定价。

九、出手建议 按你 160 万预算

  1. 想买就只买那一套：88.33㎡ / 139 万（高/6，满五唯一、无抵押）。它是 160 万以内唯一"正规商品房 + 板楼 + 税费干净"的两房，报价 15,737 已低于两房锚。出 135 万起、138 万封顶，落地约 142–143 万。代价必须接受：顶楼步梯、装修要重做（留 10–12 万）。
  2. 如果只需要小两房、能接受面积，73.31㎡/118 万（河景）比 74.65㎡/148 万合理得多——同一功能，便宜 30 万。
